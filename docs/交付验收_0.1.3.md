## 使用

当前服务已经启动，不需要再次安装。安装目录内的 `Start-Admin.cmd`、`Check.cmd`、`Stop.cmd` 分别负责按需启动、检查和停止本项目。停止再启动的生产复验状态如上，不能把脚本存在本身视为通过。

创建 ChatGPT 连接时运行 `Connect-ChatGPT.cmd`；该入口将五分钟、一次性的配对码复制到**本机剪贴板**。在 ChatGPT 开发者模式中用 `https://codex-control.aiwsb.site/mcp` 创建 OAuth 连接，动态注册时不必手填 Client ID/Secret，在本项目 HTTPS 批准页粘贴配对码并明确授权。不要把配对码、Bearer、OpenAI 凭据或隧道凭据发到聊天。

本项目没有自动开机触发，电脑重启后需要手动启动。包内不含私人令牌或已安装官方 Codex，迁移到另一台机器不是免配置即用。
