## 5. 使用与安全边界

主程序支持 `install`、`status`、`doctor`、`serve`、`version`、`capabilities`。当前已安装，无须重装。执行安装目录中的 `Codex-Control-MCP.exe doctor --active` 可以复查实际服务；`Start-Admin.cmd` 使用已校验归属的按需任务。

高权限配置意味着指令会直接影响本机。不要向未知客户端提供完整控制凭据，不要把 loopback HTTP 直接裸露到公网。没有开启开机自启，因此 Windows 重启后需要手动启动本项目任务。普通启动仍受正常 Windows 权限和 UAC 约束，不会伪装为 SYSTEM。
